# devloop

The source of the devloop plugin. Test the script with
`node --test scripts/detect.test.mjs`.

## This repository is public

Nothing learned from a project goes in here: no learnings entries, requirements,
project names, paths, or examples taken from real work. Use generic examples. A
lesson only belongs in the engine once it is rewritten as a general rule and the
developer has agreed to it.

## Superpowers and the dev loop

Devloop owns design, planning, execution and integration, and this repository
does not run its own loop. This rule overrides the Superpowers skills, including
their instruction to use a skill whenever one might apply.

- Use only these Superpowers skills: `systematic-debugging`,
  `verification-before-completion`, `receiving-code-review`, and `writing-skills`
  when editing a skill.
- Do not use any other Superpowers skill.
- Never push or merge unless the developer asks.
