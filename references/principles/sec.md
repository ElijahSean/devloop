# SEC: security

- **SEC-1 Security is always required,** even when unlisted. (FoSA 4)
- **SEC-2 Guard every door.** Check who is calling and what they may do at each interface, not just the perimeter. Deny by default. (Serverless 4)
- **SEC-3 Least privilege for people, code and agents.** Grant the narrowest access that works. (Serverless 4)
- **SEC-4 Threat-model early.** A design flaw found before code is far cheaper to fix. (Serverless 4; FoSA 22)
- **SEC-5 Never commit or log secrets.** Check diffs, logs and prompts. (Serverless 4; AIE 10)
